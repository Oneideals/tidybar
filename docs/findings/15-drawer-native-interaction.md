# 抽屉原生菜单、按钮分界与原样图标

日期：2026-09-10。

用户要求：抽屉图标支持软件本身的右键菜单；常显图标一直在 TidyBar 按钮右侧，隐藏项展开在左侧；抽屉沿用实际菜单栏图标样式。

## 修复

- 抽屉原来在鼠标按下时触发，用户随后的抬起可能关闭刚出现的菜单。现在只在按下、抬起命中同一图标时转发。
- 原来的右键路径会从 `AXShowMenu` 回退到 `AXPress`，且目标仍可能在屏外。抽屉和搜索现在先暂时展开目标、准备短应用菜单，再由串行队列发送真实鼠标事件；右键始终发送 `rightMouseDown/rightMouseUp`。普通隐藏项的点击不会展开“始终隐藏”区。
- 点击前复核会话、鼠标键、输入变化、显示器、当前帧和真实 AX 命中。取消或退出仍释放本次按下；退出等待输入队列排空。检测到原生菜单后保持访问，连续确认菜单关闭再收起；发送成功与观察到菜单分别记录。
- 中断或换屏后的抬键使用当前实际光标位置。菜单树未读完或 AX 失败时保留未知；持续未知会有界释放输入队列，保留展开与短菜单访问，交由用户点击按钮、打开设置或切换应用结束，避免误关闭菜单或永久卡住入口。
- 分区验收、自动整理、手动归类及同步落点统一以按钮作为常显边界。手动归类后重新整理分隔符，避免按钮与隐藏边界之间夹入常显项。
- 抽屉原来忽略已有位图，使用应用图标。现在直接绘制菜单栏截图，保留实际比例和宽文字；超宽内容换行，提示文字占用实际高度。
- 在图标仍可见且短菜单会话仍持有时预热，每个显示器只抓一条菜单栏区域并本地裁切。截图前后验证身份、位置、命中与调用状态。验证过的截图随图标身份缓存，折叠到负坐标不会作废或再次抓屏外区域。
- 整理返回的新帧通过专用入口落地，预热期间继续保持 busy。普通后台扫描仍被拒绝，避免新结果被守卫丢弃而拿旧坐标截图；预热期间的真实手动拖动会取消旧整理结果。
- 缺少屏幕录制权限时显示明确占位及授权入口，不用应用图标冒充。另提供菜单入口更新权限或刷新截图。
- 同时保留上一轮对空扫描、部分扫描后恢复已提交分区内顺序的修复。
